# DungeonGenerator

A Unity project showcasing the procedural dungeon generator I worked on for *Periwinkle's Adventure*, a 2015 capstone game. The original game was a top-down roguelike inspired by *The Binding of Isaac*, and its interconnected room layouts drew on that same inspiration.

## What's included

- Procedural dungeon layouts and room placement
- Door placement between connected rooms
- Object placement within rooms
- Camera navigation for exploring the generated layout

This repository contains the dungeon generation system extracted from the capstone. It does not include the full game.

## Opening the project

Clone the repository and open the project folder in Unity Hub. The project settings specify Unity **6000.3.1f1**.
